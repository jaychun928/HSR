은하열차가 지나온 네 개의 세계를 막과 장 단위로 정리한 목차다. 우주정거장 헤르타의 프롤로그에서 시작해 야릴로-VI의 영원한 겨울, 선주 나부의 불멸의 거목을 지나 페나코니의 꿈까지 이어진다.

장마다 사건의 줄거리와 이어지는 횡단 단서를 두고, 원문이 남아 있는 장에는 대사 앵커를 함께 둔다. 페나코니는 2.0~2.3 네 막을 묶은 통합본으로 따로 열린다.

횡단 단서

페나코니로 이어지는 실

1버전에서 심어진 단서가 2.0~2.3에서 회수되는 지점. 각 장의 단서 표시가 이 목록으로 연결된다.

  1. A

    엘리오의 「각본」

    히메코가 1.0 헤르타에서 스텔라론을 심은 데는 장기적 의도가 있다고 짚은 자리에서 시작한다. 1.2 나부의 웰트, 1.3 위령제의 부현을 거쳐, 2.1 샘과 2.2 반디가 받은 같은 지시 — 「은하열차가 『성대한 유산』을 쫓게 만들어라」 — 로 모인다.

    1.0 → 2.2
  2. B

    무명객의 유산과 「시계공」 미하일

    1.0 헤르타에서 히메코가 은하열차가 「개척」의 아키비리가 만든 도구임을 설명한 데서 출발한다. 2.0 페나코니에서 폼폼이 옛 무명객의 정보를 부탁하고, 2.1 갤러거와 2.2 웰트의 증언을 거쳐 「시계공」 미하일의 정체로 좁혀진다.

    1.0 → 2.2
  3. C

    결맹 옥자의 이동

    1.3 위령제에서 경원이 나부와 열차의 동맹 증표로 건넨 결맹 옥조가 2.0 페나코니에서 상대를 설득하는 증표가 되고, 2.2에는 단항이 옥조로 열차 팀을 구한다.

    1.3 → 2.2
  4. D

    페나코니 예고와 「감옥 행성」

    1.3 위령제에서 히메코가 페나코니를 컴퍼니가 범죄자를 유배시킨 「감옥 행성」이라 설명하고 「가족」의 초대를 받아들인다. 2.0의 초대장과 2.4 나부의 나타샤 대사가 같은 이름을 다시 부른다.

    1.3 → 2.4
  5. E

    야릴로 사람들이 선주에 오다

    1.0 야릴로에서 클라라와 서벌이 남긴 인연이 2.3 페나코니의 토파즈를 거쳐, 2.5 나부의 연무 의식에 루카·훅·링스가 참가하는 자리로 이어진다.

    1.0 → 2.5
  6. F

    「화합」의 이면, 「질서」

    2.0 헤르타에서 읽히는 ≪조화의 송가≫의 문장이, 2.2 페나코니에서 선데이·블랙 스완·아케론의 입을 통해 「화합」의 시페가 「질서」의 에나를 흡수했다는 사실로 이어진다.

    2.0 → 2.2
  7. G

    은랑의 코드, 샘의 정체

    1.0 헤르타에서 은랑이 남긴 코드가 2.0 페나코니의 문을 열고, 「불꽃 기사」 샘의 정체는 2.2에서 반디의 고백과 블레이드의 신호로 확정된다.

    1.0 → 2.2
  8. H

    지니어스와 스크루룸

    1.0 헤르타에서 카프카가 스크루룸을 「은랑의 오랜 라이벌」이라 부른 자리에서 시작해, 1.6에서 스크루룸이 명화를 가두고, 2.2에서 레이시오가 스크루룸에게 마지막 발언을 넘긴다.

    1.0 → 2.2
